# Terraform Practice

This repository contains Terraform configurations and related files for various practice scenarios.

## Structure
- `backend_demo/` – Example of a remote backend configuration.
- `vpc-module/` – VPC module implementation.
- `ec2-modulex/` – EC2 instance module.
- `jenkins-master-slave/` – Jenkins CI/CD setup.
- `mynewterraform/` – Additional practice modules.
- `new-jenkins/` – Another Jenkins example.
- `Dockker-terra/` – Dockerized Terraform environment.
- `state_lock/` – State locking examples.
- Root files such as `main.tf`, `variables.tf`, `terraform.tfvars`, etc.

## Usage
```bash
terraform init
terraform plan
terraform apply
```

Feel free to explore and modify the configurations.
